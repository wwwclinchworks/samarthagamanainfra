# Samartha Gamana Infra

Dark cinematic site for **Samartha Gamana Infra** — particle intro, procedural 3D city, then a long scroll from land to landmark. Homepage look is fixed (basalt, brass, Inter / Fraunces / Big Shoulders / IBM Plex Mono). Inner pages reuse the same type, parcels, and development panels.

Dummy inventory only. Live stock is confirmed on WhatsApp.

## Local

```bash
npm install
npm run dev
```

Dev server: [http://127.0.0.1:45217](http://127.0.0.1:45217).

```bash
npm run build
npm run preview
```
