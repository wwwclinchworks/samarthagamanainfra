# Samartha Gamana Infra

Dark cinematic marketing site for **Samartha Gamana Infra** — particle intro, procedural 3D city, then a long scroll from land to landmark.

## Local

```bash
npm install
npm run dev
```

Opens on [http://127.0.0.1:45217](http://127.0.0.1:45217).

## Pages

- `/` — intro + 3D city, origin, parcels, scale, developments, process, contact
- `/about`, `/projects`, `/ongoing`, `/upcoming`, `/contact`
- `/what-we-do/:slug` — plots, apartments, villas, commercial, farmlands
